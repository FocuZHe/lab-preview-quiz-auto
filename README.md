# 实验预习答题助手

某高校「实验预习答题系统」（内网）的自动答题工具。单文件 Python 脚本，
附带 Windows 免安装 exe，也可以自己打包。

> ⚠️ **仅供学习交流与个人核对答案使用。** 请自行确认这种做法是否符合你所在课程
> 与学校的规定。作者不对使用后果负责。

---

## 它解决什么问题

这类答题系统为了防作弊，做了两个设计：

1. **每次取卷，题序和选项顺序都会重新随机打乱** —— 所以把上次的答案
   （`A`/`B`/`C`/`D`）照抄一遍必然全错；
2. 交卷时必须回传**本次取卷**拿到的 `question_order` / `option_orders`。

但它有两个可以利用的事实：

- **选项字母会变，选项文字不变。**
- **题目内容对所有账户完全一致**，只有顺序随机。

于是可以做一张「题干 → 正确选项文字」的题库，并且跨账户复用：
新账户第一次交卷就能拿满分。

---

## 工作原理

### 1. 共享题库直交

题库存在 `bank.json`，键是题干，值是**正确选项的文字**（不是字母）。
答题时按文字在当前选项里反查字母，所以顺序怎么变都不影响。

题干会「撞车」—— 不同实验里都有「本实验的实验目的是()」这种同题干、不同选项的题。
所以一个题干下允许存**多条**候选规格，只有「能唯一命中本次取卷某个选项」的那条才会被采用；
命中不唯一就退到下面的探测流程（多花一次机会，但不会错）。

### 2. 探测 → 阅卷 PDF → 重交

题库没覆盖时：

1. 先随便交一次（消耗 1 次机会），拿到 `attempt_id`；
2. 下载这次作答的**阅卷 PDF**（服务端异步生成，需要轮询重试）；
3. 从 PDF 里解析出每题的标准答案；
4. **重新取卷**（顺序又变了），把标准答案的文字映射成新卷的字母，再交一次。

### 3. 自纠正闭环

任何一次提交只要没拿到满分，自动进入纠正流程：

- 用**这一次**的 `attempt_id` 下载阅卷 PDF（不是翻历史，历史里没有刚交的这次）；
- 逐题比对「我选的选项文字」和「标准答案选项文字」，把错题打印出来；
- **只改答错的题**，答对的保持原选择不动（按文字映射回新卷的字母）；
- 重新取卷后重交 — 只要还有剩余次数就一直循环，直到满分。

### 4. 自学习

纠正过程中拿到的标准答案会写回 `bank.json`（只补空缺、只修单规格的错误项，
多规格的只追加以免误删其它实验的答案）。这样下次运行、甚至别的账户，就不用再错了。

## 使用方法

### 方式一：免安装 exe

到 [Releases](https://github.com/FocuZHe/lab-preview-quiz-auto/releases) 下载
`lab-quiz-assistant-v1.0.0.exe`（约 42 MB），放到任意**可写**目录
（别放 `C:\Program Files`），双击，按提示输入学号、密码即可。下载后可以随便改名。

第一次运行会在旁边生成 `bank.json`（题库）。

> 附件用英文名是因为 GitHub 会把非 ASCII 的 Release 附件名规范化成 `default.exe`。

### 方式二：Python 脚本

```bash
pip install pdfplumber

python lab_quiz.py -u 学号 -p 密码 summary   # 看有哪些卷子、各得多少分
python lab_quiz.py -u 学号 -p 密码 solve     # 全部做完（幂等，可反复跑）
```

Windows 上也可以直接双击 `一键答题.bat`（等价于下面的 `interactive`）。

依赖缺失时会**自动 pip 安装**（默认源 → +`--user` → 清华源 → +`--user`）。
想关掉自动安装，设环境变量 `LABQUIZ_NO_INSTALL=1`。

### 多账户

```bash
python lab_quiz.py --account A:passA --account B:passB solve
python lab_quiz.py --accounts-file accounts.json solve     # {"a":"passA", ...}
```

### 常用参数

| 参数 | 说明 |
|---|---|
| `--id 3,5,9` | 只处理指定卷号 |
| `--dry-run` | 只算答案、不交卷 |
| `--force` | 已满分的也重做 |
| `--only-undone` | 跳过已标记预习完成的 |
| `--no-bank` | 不用共享题库，强制走探测流程 |
| `--no-retry` | 提交未满分时不自动纠正 |
| `--no-learn` | 不把标准答案回写题库 |
| `--no-pdf` | 不自动导出阅卷 PDF |
| `--pdf-dir <目录>` | 指定阅卷 PDF 导出位置 |
| `--base <url>` | API 根地址（默认 `http://172.25.75.220/api`） |

### 子命令

| 命令 | 说明 |
|---|---|
| `interactive` | 傻瓜模式：问学号密码，然后直接全部做完 |
| `summary` | 列出全部预习任务与得分 |
| `solve` | 自动处理（幂等，可反复跑） |
| `build-bank` | 由已满分的账户生成共享题库 |
| `verify-bank` | 校验题库解与阅卷 PDF 解是否一致 |
| `finish` | 用已有作答 PDF 直接交卷（省一次探测） |
| `check` | 用已有 PDF 干跑校验，不交卷 |
| `parse` | 打印某份阅卷 PDF 的解析结果 |
| `shots` | 把阅卷 PDF 渲染成图片 |

## 输出

跑完会自动把每份卷子**得分最高那次**的阅卷 PDF 导出到 `阅卷PDF/`，
文件名形如：

```
01_弗兰克-赫兹实验_100分.pdf
03_密立根油滴实验_100分.pdf
```

同名文件会自动跳过，所以反复运行不会重复下载。

## 自己打包 exe

```bash
pip install pyinstaller pdfplumber

python -m PyInstaller --onefile --console --noconfirm --name labquiz ^
  --add-data "bank.json;." ^
  --collect-all pdfplumber --collect-all pdfminer --collect-all pypdfium2 --collect-all PIL ^
  lab_quiz.py
```

也可以直接双击 `build_exe.bat`。

打包时有两个坑：

- `--collect-all pdfminer` 不能省（需要 cmap 数据文件），`pypdfium2` 的二进制同理，
  否则 exe 起来后解析 PDF 会挂；
- 程序里的输出目录按 `sys.frozen` 区分：打包后必须用「exe 所在目录」，
  否则题库会被写到 PyInstaller 的临时解压目录，程序一关就没了。

## 关于 PDF 解析的几个坑

解析阅卷 PDF 用 `pdfplumber`，踩过的坑记录如下，改代码时注意：

1. **判断题没有选项**，标准答案直接是 `T` / `F`；
2. **选项可能超过 4 个**（到 E、F…），正则别写死 `[A-D]`；
3. **选项是公式图片**时，PDF 里提不出文字 —— 需要人工核对后用 `overrides.json`
   指定「题干关键词 → 正确选项文字片段」；
4. **题干里的公式图片也会丢**，所以 PDF 题干可能是接口题干的**子序列**，
   匹配时要有子序列兜底；
5. **题干里的枚举逗号会被误判成选项标记**：「系数A、S很难测定」里的 `A、`
   会被当成选项 A，需要专门处理；
6. PDF 用的是压缩交叉引用表，必须走 pdfminer 解析，不能直接正则二进制。

## 已知限制

- 只在 Windows 上测试过（`.bat` 和 exe 都是 Windows 的）；脚本本身跨平台，但没验证。
- 公式类选项需要人工配置 `overrides.json`。
- 站点地址是写死的默认值，换环境请用 `--base`。
